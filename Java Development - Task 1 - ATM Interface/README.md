# ATM Interface Using Core Java

## Project Description
A console-based ATM simulation developed using Core Java and object-oriented programming concepts.

## Features
- User ID and PIN verification
- Check account balance
- Deposit money
- Withdraw money
- View transaction history
- Limit incorrect PIN attempts to three

## Technologies
- Java
- Eclipse IDE
- Object-Oriented Programming

## Sample Login
- User ID: `USER101`
- PIN: `1234`

## Note
This is an educational simulation. Account balances and transaction history are stored in memory.
