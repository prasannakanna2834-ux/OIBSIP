Number Guessing Game

Project Description

A console-based Java game in which the computer generates a random number between 1 and 100. The player has a maximum of seven valid attempts to guess the number.

Features

Random number generation

Too High and Too Low hints

Seven attempts per round

Winning and losing messages

Input validation

Round and guess tracking

Play again option

Technologies Used

Java

Eclipse IDE

Scanner class

Random class

How to Run

Install Java JDK.

Open Eclipse IDE.

Import the Java project or create a new Java project.

Open NumberGuessingGame.java.

Run it as a Java Application.

Enter your guesses in the Console.

Learning Outcomes

This project demonstrates Java variables, loops, conditional statements, random number generation, user input, and input validation.
