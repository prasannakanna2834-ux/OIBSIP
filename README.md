
# Number Guessing Game

## Project Overview
A console-based Java game where the computer generates a random number between 1 and 100. The player has up to seven valid attempts to guess the number.

## Features
- Random number generation
- Too High and Too Low hints
- Maximum of seven valid guesses per round
- Winning and losing messages
- Input validation
- Round and guess tracking
- Play-again option

## Technologies
- Java
- Eclipse IDE
- Scanner and Random classes

## How to Run
1. Install a Java JDK.
2. Open the project in Eclipse.
3. Run `NumberGuessingGame.java` as a Java Application.
4. Enter guesses in the Console.
